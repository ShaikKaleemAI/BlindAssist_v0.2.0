# Dataset card
Sources + licences: docs/generated/DATA_LICENSES.md. Counts per class/split: docs/generated/DATASET_STATS.md (generated by `ml/open_data/build_dataset.py`; PENDING until the pipeline is run).
Classes (13): see ml/open_data/sources.yaml `unified_classes`. Splits: deterministic hash split; optional `--holdout-source` puts a whole source in TEST for a cross-domain estimate. Exact duplicates removed; images with no mapped labels dropped; unmapped classes counted, never guessed.
Known biases/limits: web photos (not pocket-height walking video), mostly non-Indian scenes except IDD, no stairs direction, noisy drain labels, small sets for several hazard classes.
